Являясь ключевым разработчиком пакета продуктов для персонального облака Synchronoss (https://synchronoss.com/products/cloud/personal-cloud-solution/), я работал над несколькими ключевыми сервисами и общими библиотеками, повышая функциональность и надежность платформы.

Основные сервисы включают:

* *Collection Manager* - управляет медиаконтентом для фотоальбомов и музыкальных плейлистов.

* *Message Minder* - предоставляет API-интерфейсы для резервного копирования, восстановления журналов вызовов, SMS, MMS и RCS-сообщений и управления ими с мобильных устройств пользователей

* *Digital Vault* -- управляет метаданными о контенте, резервными копиями которого являются мобильные и настольные устройства

* *Cloud Share* -- позволяет обмениваться загруженным контентом с другими пользователями

* *Smart Albums* -- использует информацию о геолокации и временных метках для автоматического создания и ведения альбомов

* Перенесены компоненты Message Minder и ATP в Spring Boot 1.5, обновив реализацию JAX-RS до версии Jersey 2

* Реализована поддержка RCS-сообщений в Message Minder, что обеспечивает плавную интеграцию с мобильными устройствами.

* Переработаны механизмы сохранения данных в Message Minder для устранения недостатков проектирования и предотвращения повреждения данных в кластерах базы данных Cassandra.

* В Digital Vault добавлена поддержка семейного доступа, позволяющая членам семьи совместно использовать квоты и контент

* Введена концепция спецификации материалов для обеспечения согласованного использования сторонних библиотек в основных сервисах и общих библиотеках
